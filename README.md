# Fork Flip

A coin flip, but it's a fork. Call **tines** or **handle**, watch it spin, find out.

**Play:** https://the-trenches-team.github.io/fork-flip/

- One file, no build, no dependencies, no wallet.
- 50/50 via `crypto.getRandomValues` with modulo-bias rejection — no house edge.
- Tracks wins, flips, current streak and best streak in `localStorage`.
- Keyboard: `T` for tines, `H` for handle.

## Run locally

Open `index.html` in a browser. That's it.
